# 💻 Frontend Day 3

Repository นี้รวบรวมแบบฝึกหัดและเวิร์กชอปสำหรับการเรียนรู้การพัฒนาเว็บฝั่ง Frontend (Day 3) โดยเน้นไปที่การจัดการ DOM (Document Object Model), การจัดการ Event และการนำมาประยุกต์ใช้งานจริง

## 📂 โครงสร้างของโปรเจกต์ (Repository Structure)

โปรเจกต์นี้ประกอบด้วย 3 ส่วนหลักเพื่อการเรียนรู้และฝึกปฏิบัติ:

- 📁 **`Dom_Lab/`**
  แบบฝึกหัดที่เน้นการจัดการ DOM เรียนรู้วิธีการใช้ JavaScript ในการเข้าถึง ปรับเปลี่ยน และสร้าง Elements ต่างๆ บนหน้าเว็บเพจ
- 📁 **`Event_Lab/`**
  แบบฝึกหัดเกี่ยวกับการจัดการเหตุการณ์ (Event Handling) เพื่อทำให้เว็บไซต์สามารถโต้ตอบ (Interactive) กับผู้ใช้งานได้ เช่น การคลิกปุ่ม หรือการพิมพ์ข้อความลงฟอร์ม
- 📁 **`workshop/`**
  โปรเจกต์เวิร์กชอปที่นำเอาความรู้จากเรื่อง DOM และ Event มาประยุกต์ใช้งานร่วมกันเพื่อสร้างชิ้นงาน

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **HTML** - สำหรับวางโครงสร้างหน้าเว็บ
- **JavaScript (Vanilla JS)** - สำหรับจัดการ DOM และ Event ต่างๆ
- **PHP** - สำหรับการประมวลผลหรือรับส่งข้อมูลเบื้องต้น

## 🚀 การติดตั้งและการใช้งานเบื้องต้น

**โคลน Repository นี้** ลงในเครื่องของคุณ:
   ```bash
   git clone [https://github.com/gatunyus/Frontend_Day3.git](https://github.com/gatunyus/Frontend_Day3.git)
   ```
**เข้าสู่โฟลเดอร์โปรเจกต์**:
   ```bash
   cd Frontend_Day3
   ```
**การรันเพื่อดูผลลัพธ์**:
   - สำหรับไฟล์นามสกุล `.html` คุณสามารถดับเบิลคลิกเพื่อเปิดดูผลลัพธ์บน Web Browser (เช่น Google Chrome, Edge) ได้ทันที
   - หากมีการทำงานที่เกี่ยวข้องกับไฟล์ `.php` ให้รันผ่าน Local Server (เช่น การใช้ XAMPP, MAMP หรือ Extension อย่าง PHP Server ใน VS Code)
```

คุณสามารถกดที่ปุ่ม Copy (คัดลอก) มุมขวาบนของกล่องข้อความนี้ แล้วนำไปวางในหน้า Edit ของไฟล์ `README.md` บน GitHub ได้เลยครับ หากต้องการให้ปรับข้อความส่วนไหนเพิ่มเติมบอกได้เลยครับ
